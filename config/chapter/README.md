# 闯关章节配置说明

本文档说明 `config/chapter/` 目录下章节关卡配置（`chapter_0.json`、`chapter_1.json`、`chapter_2.json`）的生成规则与字段含义。

## 1. 章节总览

共 5 个章节、240 个关卡，`index` 全局连续编号 0-239。

| 文件 | 章节 | 关数 | index | 关卡类型 | Boss 关（index） |
|---|---|---|---|---|---|
| `chapter_0.json` | 1 | 30 | 0-29 | 全部 type=2（计分） | 9, 19, 29 |
| `chapter_1.json` | 2 | 40 | 30-69 | 全部 type=1（计时） | 39, 49, 59, 69 |
| `chapter_2.json` | 3 | 50 | 70-119 | 每 10 关轮换 type=2/1（70-79 起） | 79, 89, 99, 109, 119 |
| `chapter_3.json` | 4 | 60 | 120-179 | 每 10 关轮换 type=2/1（120-129 起） | 129, 139, 149, 159, 169, 179 |
| `chapter_4.json` | 5 | 60 | 180-239 | 每 10 关轮换 type=2/1（180-189 起） | 每组末 2 关：188, 189, 198, 199, 208, 209, 218, 219, 228, 229, 238, 239 |

所有关卡 `energy = 5`，`chapter` 字段与文件名章节号一致。章1-3（chapter_0/1/2）Boss 关开启「消除后挤压移动」玩法（`shiftDir`/`shiftEdge`，方向按模板图形，移动时尽量不破坏图形形状），普通关不移动。第四章（chapter_3）难度在第三章基础上再增一档，仅 Boss 关开启挤压玩法（普通关不移动）。第五章（chapter_4）Boss 关 `energy = 10`，且仅 Boss 关开启挤压移动，难度再增一档。

## 2. 关卡字段说明

对应代码接口 `MAP_LEVEL_CONFIG`（`assets/scripts/datacenter/ChallengeData.ts`）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `chapter` | number | 章节索引（与文件名一致：0/1/2） |
| `index` | number | 关卡索引，全局连续 0-239 |
| `map` | number[][] | 16×10 二维数组：`0`=边界/空位，`1`=可放置方块。外圈（首尾行、首尾列）恒为 0，`1` 的个数恒为双数且 ≥48 |
| `iconTypes` | number | 方块图标种类数，值越大越难。范围 [6, 22] 且 ≤ 对子数 |
| `type` | number | 关卡规则：`1`=计时规则，`2`=计分规则 |
| `boss` | number | 是否 Boss 关：`1` 是，`0` 否 |
| `energy` | number | 体力消耗，恒为 5（第五章 Boss 关为 10） |
| `totalTime` | number | 总时间（秒），仅 type=1 使用 |
| `starTime` | number[] | 星级剩余时间阈值（秒），仅 type=1 使用，索引 0/1/2 对应 1/2/3 颗星 |
| `starScore` | number[] | 星级分数阈值，仅 type=2 使用，索引 0/1/2 对应 1/2/3 颗星 |
| `targetScore` | number | 过关目标分数（type=2），总分 ≥ 该值才算过关 |
| `shiftDir` | number | 消除后方块移动方向（可选，缺省关闭）：`0`=关闭，`2`=向上，`3`=向下，`4`=向左，`5`=向右（`1`=随机，代码中视为关闭）。章1-4 仅 Boss 关配置，方向按模板图形选定：三角模板（上窄下宽）固定 `3`（向下压缩各列保持连续填充，轮廓不变），全满等对称模板无形状约束取固定 seed 随机 2-5 |
| `shiftEdge` | number | 方块移动的最边边位置（可选，缺省 2）：方块最多贴到第 edge 行/列，留出外圈空位供连线走位 |

> 注：type=2 关卡不配置 `totalTime`/`starTime`（无倒计时，消除完即结束）。

## 4. 数值公式（以对子数 p 推导）

p = map 中 `1` 的个数 ÷ 2。

### iconTypes（方块种类数）

```
iconTypes = clamp(round(p × 0.35) + (boss ? 3 : 0), 6, 22)
```

- 上限 22（不能超过 22 种），下限 6
- Boss 关在基础值上 +3

### type=2（计分规则）

```
starScore = [p, p + round(p × 0.5), p × 2]
targetScore = p
```

Boss 关（3 星难度加大）：

```
starScore = [p, p + round(p × 0.7), round(p × 2.5)]
targetScore = round(p × 1.2)
```

星级含义（无需连击时每对固定 1 分）：
- 1 星：p 分（所有消除无连击）
- 2 星：中等（在 1 星基础上加 50%）
- 3 星：快（约需全程保持连击，如一条大连击链）

### type=1（计时规则，剩余时间语义）

星级判定按**剩余时间**：通关时剩余时间 ≥ starTime[i] 得 i+1 颗星。

普通关（对应 2/4/6 秒每对）：

```
totalTime = 6p + 15
starTime  = [15, 2p + 15, 4p + 15]
```

| 星级 | 用时要求 | 换算 |
|---|---|---|
| 1 星 | 剩余 ≥ 15s | 用时 ≤ 6p（6s/对） |
| 2 星 | 剩余 ≥ 2p+15 | 用时 ≤ 4p（4s/对） |
| 3 星 | 剩余 ≥ 4p+15 | 用时 ≤ 2p（2s/对） |

Boss 关（2/3/5 秒每对，更紧）：

```
totalTime = 5p + 15
starTime  = [15, 2p + 15, 3p + 15]
```

| 星级 | 用时要求 | 换算 |
|---|---|---|
| 1 星 | 剩余 ≥ 15s | 用时 ≤ 5p（5s/对） |
| 2 星 | 剩余 ≥ 2p+15 | 用时 ≤ 3p（3s/对） |
| 3 星 | 剩余 ≥ 3p+15 | 用时 ≤ 2p（2s/对） |

## 5. 难度爬坡规则

每章/每组 10 关的普通关按阶段序列爬坡（对子数递增），Boss 关为该阶段峰值：

| 阶段 | 对子数序列 | Boss 对子数 |
|---|---|---|
| 前期 | 24, 24, 28, 32, 36, 36, 40, 42, 44 | 50 |
| 中期 | 32, 36, 36, 40, 42, 44, 50, 56, 50 | 56 |
| 后期 | 36, 36, 40, 42, 44, 50, 56, 50, 44 | 56 |

- 章1：前期 → 中期 → 后期
- 章2：前期 → 中期 × 2 → 后期
- 章3：每组 10 关依次采用 前期 / 中期 / 中期 / 后期 / 中期 序列（type 交替）

|---|---|---|

## 5.1 第四章（chapter_3）进阶数值公式

第四章在第三章基础上难度再增一档，仅 Boss 关开启挤压玩法（普通关不移动）：

- `iconTypes`：全部顶格 **22**
- `shiftDir`：仅 Boss 关开启，方向按模板图形（本章 Boss 全为全满模板，图形对称无形状约束 → 固定 seed 随机 2-5，可复现）；`shiftEdge` 全部 2
- 对子数起步 36（≥36）

**type=2（计分）**：

```
starScore = [round(1.1p), p + round(0.6p), round(2.2p)]
targetScore = round(1.1p)
```

Boss 关（3 星难度加大）：

```
starScore = [round(1.3p), p + round(0.8p), round(2.8p)]
targetScore = round(1.3p)
```

过关门槛即 1 星门槛（targetScore = starScore[0]）。

**type=1（计时）**（每对秒数再收紧）：

普通关（1.5/2.5/4 秒每对）：

```
totalTime = 4p + 15
starTime  = [15, 1.5p + 15, 2.5p + 15]
```

Boss 关（1.5/2/3 秒每对）：

```
totalTime = 3p + 15
starTime  = [15, p + 15, 1.5p + 15]
```

| 星级 | 普通关用时 | Boss 用时 |
|---|---|---|
| 1 星 | ≤ 4p（4s/对） | ≤ 3p（3s/对） |
| 2 星 | ≤ 2.5p（2.5s/对） | ≤ 2p（2s/对） |
| 3 星 | ≤ 1.5p（1.5s/对） | ≤ 1.5p（1.5s/对） |

## 5.2 第五章（chapter_4）进阶数值公式

第五章在第四章基础上难度再增一档，仅 Boss 关开启挤压玩法（`shiftDir` 随机 2-5、`shiftEdge`=2，固定 seed 20260813），Boss 关体力 10（普通 5）：

- `iconTypes`：全部顶格 **22**
- 对子数：组1-2 起步 40、组3-4 起步 45、组5-6 起步 50，Boss 全 56

**type=2（计分）**：

```
starScore = [2.5p, 3.5p, 4.5p]
targetScore = 2.5p
```

Boss 关（3 星难度加大）：

```
starScore = [3p, 4p, 5p]
targetScore = 3p
```

过关门槛即 1 星门槛（targetScore = starScore[0]）。

**type=1（计时）**：

普通关：

```
totalTime = 4.5p
starTime  = [p, 2p + 15, 3p]
```

Boss 关：

```
totalTime = 3p + 30
starTime  = [p, p + 15, 2p + 10]
```

| 星级 | 普通关用时 | Boss 用时 |
|---|---|---|

## 6. 生成与校验规则

配置文件由生成脚本 `tools/gen_chapter.js` 产出（模板库 + 逐关映射表 + 数值公式，确定性输出），运行方式：

```
node tools/gen_chapter.js config/chapter
```

- 生成结果可复现：章1-4 Boss 关 `shiftDir` 使用固定 seed（20260812）伪随机（三角模板固定向下，不消耗随机序列）
- 生成脚本内置全部校验断言，不满足即报错退出；生成后建议按下列清单复核：

1. 地图 16 行 × 10 列，外圈（首尾行/列）全为 0
2. `1` 的个数为双数且 ≥ 48（方块数至少 48）
3. `iconTypes` ∈ [6, 22] 且 ≤ 对子数 p（保证每种图标成对可完全消除）
4. type=1：`starTime` 严格递增，且 `starTime[2] < totalTime`
5. type=2：`starScore` 严格递增，`targetScore` 存在
6. `index` 0-239 全局连续无重复，`chapter` 与文件名一致
7. Boss 关标记正确（`boss=1`），`energy` 恒为 5（第五章 Boss 关为 10）
8. 章1-3（chapter_0/1/2）：仅 Boss 关含 `shiftDir` 与 `shiftEdge`（2），普通关无移动；三角模板 Boss `shiftDir`=3（向下压缩保持轮廓），其余 Boss 取固定 seed 随机 2-5
9. 第四章（chapter_3）：仅 Boss 关含 `shiftDir` 与 `shiftEdge`（2），普通关无移动（本章 Boss 全为全满模板，方向随机 2-5）；`iconTypes` = 22，对子数 ≥ 36
10. 第五章（chapter_4）：`iconTypes` = 22；每组末 2 关为 Boss（`boss=1`、`energy`=10、含 `shiftDir`/`shiftEdge`），其余关 `energy`=5 且无 `shiftDir`；对子数 ≥ 40
